# Programación · 1DAW

Módulo de **Programación** del ciclo de Desarrollo de Aplicaciones Web (DAW),
curso **2026-2027**, IES Luis Vives.

## Unidades

| UD | Título | Deck |
|---|---|---|
| **UD01** | Introducción a la Programación Software | [PROG/UD01.md](UD01.md) |

## Comandos

Una línea npm por presentación, desde la raíz del proyecto:

```bash
npm run dev:UD01          # desarrollo en local
npm run build:UD01        # build de producción
npm run export:UD01       # PDF tema claro
npm run export:UD01:dark  # PDF tema oscuro
npm run check:UD01        # auditoría visual
```

Las imágenes de este módulo van en `public/PROG/<NUD>/` (las comunes a todo el
ciclo en `public/media/global/`).
